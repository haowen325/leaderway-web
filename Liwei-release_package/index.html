常見問題

客戶最常詢問的問題，為您整理如下

報價需要提供什麼資料？

請提供加工圖面（CAD 檔案或 PDF 皆可）、材質、數量與交期需求。如有特殊表面處理需求（如烤漆、電鍍），也請一併說明，我們將盡速為您報價。

可以處理哪些材質？

我們主要加工黑鐵（SPHC / SS400 等）及不鏽鋼（SUS 304 / 430 等）。這兩大類材質涵蓋了絕大多數板金加工需求。

交期大概多久？

一般訂單交期約 7～14 個工作天，視數量與製程複雜度而定。急件可配合加速處理，歡迎來電討論。

可以只做少量或單件嗎？

可以。我們從打樣、少量客製到穩定批量生產都能彈性配合，每一件都以相同品質標準製作。

沒有圖面，可以協助處理嗎？

如果您有實品或草圖，我們可以協助丈量與繪製加工圖。建議先來電或 Email 與我們討論需求，再由工程人員評估。
